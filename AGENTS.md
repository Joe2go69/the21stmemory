# 21st Memory — agent rules

When adding or updating a **topic**: follow `.grok/skills/add-topic/SKILL.md`. After writing the payload, run `node scripts/install.js topic {source} {id}` (or `all` if the quiz payload is ready too).

When adding a **quiz**: follow `.grok/skills/add-quiz/SKILL.md`. Use only that topic’s own report JSON as the source of truth. Keep NotebookLM stems and correct answers. Rewrite a wrong answer only when it is much shorter, uses a banned absolute, or is not actually false. Write the payload once. Do not count characters, run a length script, or re-read the payload. After writing, run `node scripts/install.js quiz {source} {id}` and `npm run lint:quizzes`.
Quiz answer rules (full list in the skill): wrong answers are about as long as the correct one. The checker warns when the correct answer is above 1.6× the longest wrong answer and fails above 2×. The correct answer is the longest on about a quarter of the multiple-choice items and the shortest on a few. Same grammatical shape. Wrong answers use real report terms, are actually false, and do not use only, always, never, entirely, solely, forever, completely, nothing but, or no other. No filler tails, joke options, or All/None of the above. Don't echo the question. Nothing cut off. Exactly 25 questions: ~20 multiple choice, 3–5 True/False, 1–2 "Which is NOT". Hints don't give the answer away. Each correct rationale includes an exact report phrase. Sources: alice, breakdown, revelations, ascension, special-requests.
The installer keeps answer text exactly, does a stable A–D shuffle, and lints the quiz before writing; if lint fails it exits non-zero and installs nothing. Fix only the questions it lists and rerun. Then run `node scripts/quiz-quality.js --warnings 200 | Select-String -Pattern "{id}"`. No lines means this quiz is clean. Do NOT run `scripts/rebalance-quiz-length.js` on new quizzes (legacy maintenance tool for old Alice data). Never run `quiz-quality.js --baseline` or `--fix`.

Allowed reads for those tasks: the matching skill, `data/{source}-topics/{id}.json`, the user paste or NotebookLM file, and this topic’s images. Do not read installer/pipeline files unless Verify fails.

Forbidden: exploring “how other topics work,” reading sibling reports/HTML, or cloning old install scripts. Do not run a full-site dive rebuild for a single topic. If the topic id is not already in `data/{source}-topics.json`, stop and say so — do not scan the tree to find a parent. Do not use Playwright, a browser, or a local server for topic/quiz installs — `Verify passed` from `scripts/install.js` is the check.

When asked to review, commit, and push a topic/quiz install: do not launch `/review` or a reviewer subagent. Verify passed is the review. Stage only that install’s payload, data, images, dive/quiz HTML, hub, and sitemap files. Neighbor dive rebuilds are expected. Leave unrelated files unstaged. Commit `Add {Title} topic and Living Truth quiz.` (or topic-only / quiz-only). Push only if asked. Do not write long memory notes after the install.

Sources include `alice`, `breakdown`, `ascension`, `revelations`, and `special-requests`.
